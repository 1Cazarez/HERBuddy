# HERBuddy

A Swift package starter project with Firebase SDK dependencies configured for Apple platforms.

## Project status

- Swift toolchain installed and ready to use
- Firebase Swift Package dependency resolved
- Project scaffold created in [Package.swift](Package.swift)

## Notes

This project is set up as a Swift Package Manager project for Apple platforms. It is ready to open in Xcode on macOS, where Firebase can build normally.

The current Linux container cannot compile Firebase because the Google SDKs rely on Apple Objective-C frameworks and Apple platform tooling.
